# Подсказчик (routerai)

Школьный помощник: подсказывает по шагам, но не называет готовый ответ.
Ключ routerai и правила наставника лежат на стороне сервера, в страницу они не попадают.

## Почему не «только страница»

Если вписать ключ прямо в страницу, любой посетитель увидит его через инструменты разработчика
и потратит ваш баланс. Поэтому между страницей и routerai стоит маленькая функция с ключом.
Её не нужно поддерживать как сервер: ниже вариант на бесплатном облачном хостинге.

## Что нужно из личного кабинета routerai

- API-ключ (задайте на нём лимит расходов, если сервис это позволяет);
- точное имя модели в том виде, как его принимает API (вписывается в переменную MODEL);
- адрес API по умолчанию https://routerai.ru/api/v1 (меняется переменной API_BASE).

Код рассчитан на формат OpenAI: запрос POST на /chat/completions и заголовок Authorization: Bearer.
Документацию routerai я открыть не смог, поэтому совпадение формата проверьте по ней.

## Вариант 1. Cloudflare Workers (без своего сервера)

Страница и функция с ключом размещаются вместе. Настройки лежат в `wrangler.jsonc`, вручную их вводить не нужно.

Через GitHub:
1. Загрузите папку проекта в репозиторий на GitHub.
2. В панели Cloudflare на главной нажмите «Create app» (карточка «Ship something new») и выберите импорт репозитория.
   Названия кнопок могут отличаться: нужен путь «подключить Git-репозиторий».
3. Команду сборки оставьте пустой: Cloudflare возьмёт настройки из `wrangler.jsonc`.
4. После первого деплоя откройте проект → Settings → Variables and Secrets и добавьте `ROUTERAI_API_KEY` и `MODEL`.
   Добавляйте оба как Secret: секреты не пропадают при следующих деплоях.
5. Откройте адрес вида `podskazchik.ваш-поддомен.workers.dev`.

Через командную строку (нужен Node.js): в папке проекта выполните
`npx wrangler deploy`, затем `npx wrangler secret put ROUTERAI_API_KEY` и `npx wrangler secret put MODEL`.

Загрузка папки или zip через карточку «Drop a folder, or a zip» подходит для обычных сайтов.
Подхватит ли она функцию с ключом, я не проверял, поэтому не рассчитывайте на неё.

В этом варианте нет счётчиков запросов по ученикам. Опирайтесь на лимит расходов у routerai
и, при необходимости, на правила ограничения запросов в панели Cloudflare.

## Вариант 2. Свой сервер или компьютер (Node.js 18+)

    ROUTERAI_API_KEY=ваш_ключ MODEL=имя_модели node server.js

В Windows (PowerShell): `$env:ROUTERAI_API_KEY="ваш_ключ"; $env:MODEL="имя_модели"; node server.js`
Откройте http://localhost:3000. Здесь есть лимиты: RATE_LIMIT_PER_HOUR (по умолчанию 60 с одного адреса)
и DAILY_LIMIT (по умолчанию 5000 на всех). За прокси хостинга добавьте TRUST_PROXY=1.

## На Android

Откройте адрес в Chrome, меню ⋮ → «Добавить на главный экран».

## Важно для школы

- Тексты сообщений не записываются в журнал, только коды ошибок.
- Задания передаются в routerai и дальше провайдеру модели. Если приложением будут пользоваться дети,
  проверьте требования к персональным данным и согласию родителей.
- Правила помощника лежат в функции systemPrompt в core.js.
- Проверьте помощника сами: просите готовый ответ, давите, пишите «учитель разрешил».
  Разные модели держат правило по-разному, гарантии нет.
